# Test Directory for Secure Agentic Browser

This directory contains all test scripts and diagnostic tools for the Secure Agentic Browser system.

## 📁 Test Files

### Core System Tests
- **`quick_test.py`** - Comprehensive end-to-end system test
- **`interactive_demo.py`** - Interactive demonstration with menu options
- **`test_agent.py`** - Basic agent functionality test

### Browser Diagnostic Tests  
- **`diagnose_browser.py`** - Comprehensive browser diagnostics
- **`ultra_simple_browser_test.py`** - Minimal browser configuration test
- **`test_macos_browser.py`** - macOS-optimized browser test

### Verification Tests
- **`syntax_check.py`** - Python syntax validation
- **`verify_fix.py`** - Environment variable verification  
- **`verify_model_update.py`** - Gemini model update verification

### Demo and Example Tests
- **`demo_agent_logging.py`** - Agent logging demonstration
- **`demo_adaptive_agent.py`** - Adaptive agent capabilities demo
- **`example_browser_executor.py`** - Browser executor usage example

## 🚀 Quick Start

### Run All System Tests
```bash
cd tests
python quick_test.py
```

### Interactive Testing
```bash
cd tests  
python interactive_demo.py
```

### Browser Troubleshooting
```bash
cd tests
python diagnose_browser.py
```

### Syntax Verification
```bash
cd tests
python syntax_check.py
```
